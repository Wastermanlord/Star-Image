# Star Image

Visor de imágenes ligero, rápido y multiplataforma construido con Rust + Tauri.

## Características

- Visualización rápida de imágenes (JPG, PNG, GIF, BMP, WebP, SVG, AVIF, TIFF)
- Navegación por teclado (← →, + -, F, S)
- Modo galería y vista de miniaturas
- Búsqueda por nombre de archivo
- Información EXIF completa (cámara, GPS, apertura, ISO, etc.)
- Zoom y ajuste automático
- Slideshow
- Eliminación con confirmación
- Temas claro/oscuro
